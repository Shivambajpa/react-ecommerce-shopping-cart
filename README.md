# React E-Commerce Shopping Cart

A simple React E-Commerce Shopping Cart application built using React and Vite.

## Features

- Display products from Fake Store API
- Search products by name
- Filter products by category
- Add products to cart
- Update product quantity
- Remove products from cart
- Cart data stored using Local Storage
- Responsive layout

## Tech Stack

- React
- Vite
- React Router DOM
- Context API
- CSS
- Fake Store API

## Installation

Clone the repository:

```bash
git clone https://github.com/Shivambajpa/react-ecommerce-shopping-cart.git```

Go to project folder:

```bash
cd react-ecommerce-shopping-cart
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
